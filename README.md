# Dwell Website Prototype

Interactive homepage and simplified Knowledge Keeper ATLAS demonstration for Dwell Corporation.

## Run locally

```bash
npm install
npm run dev
```

Open the client login from the homepage and use `atlas-demo`. The prototype intentionally requires no password and contains synthetic demonstration data only.

## Production boundary

The demonstration session is not production authentication. Replace it with an approved identity and authorization system before connecting ATLAS to client information. Never add private community knowledge, client documents, project maps or operational data to this public prototype.

## Review

Use `TEAM_REVIEW_CHECKLIST.md` to record approval decisions and assign content owners before expanding the prototype into the phase-one website.
